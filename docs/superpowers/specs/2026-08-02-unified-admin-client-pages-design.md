# Единый стандарт страниц клиента в админке

## Цель

Все дочерние страницы карточки клиента должны выглядеть как части одного интерфейса: компактная шапка, плотные информационные строки, небольшие пиктограммы, минимум вложенных карточек и удобные зоны нажатия не меньше 44 px.

## Область проверки

- активность;
- обучение;
- подписки;
- оплаты;
- рефералы;
- ограничения и удаления;
- устройства;
- IP входов;
- подробный результат теста;
- подробный результат домашнего задания.

## Визуальное решение

Существующие компактные страницы остаются эталоном. Экран результата получает одну компактную верхнюю строку статуса, единую полосу показателей, плоские секции вопросов и ответов без каскада крупных `ui-card`. Пиктограммы — 16–24 px, служебный текст — 10–12 px, основной — 13–14 px. На ширине 320 px показатели перестраиваются в сетку 2×2; варианты ответов сохраняют высоту не меньше 44 px и не выходят за экран.

## Ограничения

- бизнес-логика, API, права доступа и условия сброса не меняются;
- правильный ответ и ответ клиента остаются явно различимыми;
- для ДЗ сохраняются текст задания, ответ, комментарий, файлы и история сброса;
- все маршруты проверяются на 320, 390, 768, 1024 и 1440 px без горизонтального переполнения.
