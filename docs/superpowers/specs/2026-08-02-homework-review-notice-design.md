# Статус проверки ДЗ на экране модулей

## Цель

Показывать пользователю результат последней проверки домашнего задания прямо в верхнем блоке экрана «Модули», не требуя входа в урок и не полагаясь только на push-уведомление.

## Данные

Ответ `GET /learning` получает необязательное поле `latestHomeworkReview`. Оно содержит идентификатор урока, состояние `needs_revision` или `accepted`, комментарий проверяющего и время проверки. Сервер выбирает последнюю проверенную отправку текущего пользователя среди опубликованных уроков. Если проверок нет, поле равно `null`.

## Интерфейс

В `LearningProgressHero` над обычной карточкой продолжения обучения появляется компактная плашка результата:

- `needs_revision`: тревожное оформление, заголовок «Нужна доработка», название урока, комментарий администратора и действие «Исправить ДЗ»;
- `accepted`: положительное оформление, заголовок «ДЗ принято», название урока, необязательный комментарий и действие «Открыть урок».

Обычная карточка продолжения остаётся на месте. Плашка целиком является кнопкой с доступным названием и открывает соответствующий урок. Текст комментария переносится без горизонтального переполнения.

## Поведение

Последнее решение отображается до появления более нового решения. Состояние `needs_revision` визуально приоритетнее обычного продолжения, но не скрывает его. После повторной отправки и новой проверки данные обновляются при следующей загрузке экрана модулей.

## Проверка

- контракт shared-схемы принимает оба состояния и `null`;
- API-тест фиксирует выбор последней проверки текущего пользователя;
- компонентный тест проверяет статус, комментарий и переход в нужный урок;
- Playwright проверяет Android, iPhone, 320, 390, 768, 1024 и desktop без горизонтального переполнения в тёмной и светлой темах.
