# Поиск, избранное и заметки в «Модулях»

## Цель

Сделать большую библиотеку уроков удобной в ежедневном использовании: клиент быстро находит нужный материал, возвращается к сохранённым урокам и ведёт заметки прямо во время обучения.

## Проверка пересечений

В приложении уже есть карточка «Продолжить обучение» на основе последнего открытого урока и отдельная административная аналитика вовлечённости по каждому уроку. Новые дублирующие блоки для этих функций не создаются.

## Пользовательский интерфейс

### Поиск и фильтры

Над списком модулей появляется компактная строка поиска. Поиск работает без нового сетевого запроса по уже загруженным опубликованным данным: названию и описанию модуля, названию и краткому описанию урока. Регистр не учитывается, лишние пробелы нормализуются.

Рядом размещаются фильтры:

- «Все»;
- «Избранное»;
- «В процессе»;
- «Пройдено».

При поиске показываются только модули с совпавшими уроками либо совпадением в самом модуле. Подходящие модули автоматически раскрываются. Пустой результат содержит понятное сообщение и действие «Сбросить поиск».

### Избранное

На карточке урока и в просмотре урока появляется кнопка-закладка с доступной подписью. Добавление и удаление выполняются оптимистично, но при ошибке состояние откатывается и показывается уведомление. Избранное синхронизируется между устройствами и принадлежит только текущему клиенту.

### Мои заметки

В просмотре урока появляется сворачиваемый блок «Мои заметки». Он использует существующие защищённые маршруты заметок урока, которые возвращают клиенту только его записи. Клиент может добавить заметку длиной до 2000 символов и увидеть историю своих заметок с датой создания.

Заметки не показываются другим клиентам. Администраторы с правом модерации сохраняют возможность просматривать и скрывать их в существующем контуре модерации. В интерфейсе клиента это формулируется прозрачно, без обещания абсолютной приватности от администрации сервиса.

## Данные и API

Для избранного создаётся таблица `user_learning_favorites` с уникальной парой `user_id + content_item_id`, внешними ключами с каскадным удалением и датой создания.

`GET /learning` получает обратно совместимое поле `favoriteItemIds: string[]`. Добавляются идемпотентные маршруты:

- `PUT /learning/items/:id/favorite`;
- `DELETE /learning/items/:id/favorite`.

Оба маршрута требуют активную подписку, работают только от имени текущего пользователя и принимают только существующий опубликованный урок. Клиент никогда не передаёт `userId` в теле запроса.

Существующие маршруты `/learning/items/:id/comments` используются для заметок без изменения их текущей модели доступа. Поиск и фильтры выполняются на клиенте, поскольку метаданные всех доступных уроков уже загружаются на экран.

## Архитектура

Чистая логика нормализации запроса, поиска и фильтрации выносится в отдельный модуль с unit-тестами. Панель поиска и фильтров, кнопка избранного и блок заметок оформляются самостоятельными Vue-компонентами, чтобы не увеличивать и без того крупный `LearningSection.vue`.

Состояние избранного хранится в полученном прогрессе и обновляется через небольшой composable. Заметки загружаются лениво только при открытии блока, чтобы не создавать запросы для каждого урока на главном экране.

## Ошибки и доступность

- Поиск остаётся доступен при временной ошибке изменения избранного.
- Ошибка заметок показывается внутри их блока с повторной загрузкой.
- Интерактивные области не меньше 44×44 px.
- Закладка имеет `aria-pressed` и текстовую подпись для скринридера.
- Фильтры доступны с клавиатуры и не различаются только цветом.
- На ширине 320 px строка поиска и фильтры не создают горизонтальный скролл страницы.

## Проверка

- Unit-тесты поиска, фильтров и оптимистичного состояния избранного.
- API-тесты изоляции избранного между пользователями, идемпотентности и запрета доступа без активной подписки.
- Тесты заметок подтверждают, что клиент получает только собственные записи.
- Component-тесты пустого поиска, сброса, избранного и ошибок заметок.
- Мобильная визуальная проверка на 320, 390 и 768 px, широкая — на 1024 и 1440 px.
- Полные type-check, unit/integration, production build и release E2E перед публикацией.

## Вне пакета

Домашние задания, тесты, сертификаты, публичные обсуждения уроков и изменение существующей административной аналитики остаются самостоятельными этапами.

## Критерии готовности

Клиент может за несколько действий найти урок, сохранить его, отфильтровать обучение по состоянию и вести привязанные к уроку заметки. Данные избранного и заметок изолированы между клиентами, интерфейс не дублирует существующие «Продолжить обучение» и аналитику, а изменения проходят полный выпускной контур.
