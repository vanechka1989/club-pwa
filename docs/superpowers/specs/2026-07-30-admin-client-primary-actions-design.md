# Компактные основные действия клиента

## Цель

Убрать визуально отдельную кнопку персональной подписки и собрать основные действия администратора в единый аккуратный ряд.

## Интерфейс

- Под карточкой управления доступом отображаются две равные кнопки в одной строке: «Написать» и «Подписка».
- Обе кнопки имеют одинаковую высоту, ширину, радиус, типографику и размер иконок.
- «Написать» остаётся основным бирюзовым действием.
- «Подписка» получает вторичное оформление на поверхности текущей темы с акцентной рамкой и иконкой подарка; насыщенная фиолетовая заливка удаляется.
- На ширине от 320 px кнопки остаются в одной строке, текст не переносится и не создаёт горизонтальную прокрутку.
- Состояния hover, active, focus-visible и disabled согласованы с текущей дизайн-системой и не меняют геометрию элементов.

## Границы изменения

Меняется только вход в уже существующий сценарий персональной подписки и оформление блока основных действий. Модальное окно, API и платёжная логика не меняются.

## Проверка

- Компонентный тест закрепляет компактные подписи и общий контейнер действий.
- Проверяются TypeScript, web-тесты и production-сборка.
- В браузере проверяются мобильные ширины 320/390 px и отсутствие горизонтального переполнения.
