# Цены Lava по валютам и периодам

## Цель

Исправить синхронизацию каталога Lava, корректно учитывать несколько цен одной валюты для разных периодов подписки и сделать выбор валют в форме тарифа компактным и однозначным.

## Причина сбоя

Lava возвращает для одного предложения несколько записей `RUB`, `USD` и `EUR`, отличающихся `periodicity`. Таблица `payment_provider_catalog_item_prices` сейчас имеет уникальность только по `(catalog_item_id, currency)`, поэтому пакетная вставка второго периода той же валюты нарушает ограничение и откатывает всю синхронизацию.

## Модель данных и синхронизация

- Уникальная цена каталога определяется сочетанием товара, валюты и периода.
- Синхронизация сохраняет все поддерживаемые периоды и валюты одного предложения атомарно.
- Точные повторы `(currency, periodicity, amountMinor)` из внешнего ответа схлопываются; конфликтующие суммы для одной пары `(currency, periodicity)` приводят к контролируемой ошибке вместо произвольного выбора.
- Разовые цены без периода остаются отдельным набором.
- Существующие опубликованные тарифы не изменяются молча после обновления каталога.

## Выбор периода и автоподстановка

- Для разового тарифа используются цены без периода или `ONE_TIME`.
- Для рекуррентного тарифа используется набор цен, соответствующий `accessDays`: 30, 90, 180 или 365 дней.
- Выбор предложения Lava автоматически подставляет актуальные фиксированные суммы выбранного периода.
- После успешного обновления каталога открытая форма тарифа подхватывает новые суммы для уже выбранного предложения, сохраняя набор включённых администратором валют.
- Новые значения действующего тарифа попадают в рабочую конфигурацию только после нажатия «Сохранить тариф».
- Если подходящего периода нет, форма показывает понятное отсутствие цен и не позволяет сохранить некорректную привязку.

## Интерфейс валют

- Валюты отображаются отдельными компактными строками высотой не менее 48 px.
- В строке находятся кастомно ограниченный чекбокс 20×20 px, код валюты без переноса и отформатированная сумма.
- Общий стиль текстовых полей не применяется к `checkbox` и `radio`.
- Фиксированная цена Lava выводится текстом и не редактируется.
- Для динамической цены сохраняется компактное поле суммы.
- Нельзя отключить последнюю доступную валюту.

## Границы

- Клиент продолжает выбирать валюту оплаты из разрешённых администратором.
- Проверка суммы заказа и обработка webhook используют сохранённые `currency` и `amountMinor`; их контракт не меняется.
- Автоматическая синхронизация не публикует и не скрывает товары и не меняет выбор доступности каталога.
- Поддерживаются мобильные ширины от 320 px без горизонтального переполнения.

## Проверка

- Регрессионный тест воспроизводит несколько периодов одной валюты и подтверждает отсутствие конфликта хранения.
- Тесты выбора цен подтверждают фильтрацию по типу и длительности тарифа.
- Компонентные тесты подтверждают автоподстановку, сохранение включённых валют и компактную доступную разметку.
- После миграции выполняются проверка типов, все тесты, production-сборка и проверка синхронизации каталога на сервере без проведения оплаты.
