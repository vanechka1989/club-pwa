# Поток создания тарифов и каталог Lava

## Цель

Сделать создание тарифа прямым и однозначным: верхний плюс создаёт тариф, у тарифа ровно одна платёжная система, а владелец заранее определяет, какие товары Lava разрешено выбирать.

## Интерфейс

- Плюс в шапке раздела «Оплата» открывает экран «Новый тариф».
- Настройки платёжных систем остаются в режиме редактирования в блоке «Платёжные системы».
- В тарифе Prodamus и Lava отображаются как радиовыбор: активна только одна система.
- Для Lava после синхронизации показывается полный актуальный каталог. У каждого товара есть компактный переключатель «Доступен в тарифах».
- В форме тарифа выводятся только актуальные и разрешённые товары Lava нужного типа: разовые для разового тарифа, рекуррентные для подписки.
- Уже привязанный к тарифу товар остаётся видимым при редактировании, даже если позже его исключили из новых тарифов.
- Переключатель «Платёжная система включена» становится компактной строкой с обычным переключателем.

## Сервер и данные

- В `payment_provider_catalog_items` добавляется `is_selectable boolean not null default true`.
- Синхронизация сохраняет установленное владельцем значение для существующих товаров и включает новые товары по умолчанию.
- Отдельный административный endpoint меняет доступность одного товара каталога.
- Создание и редактирование тарифа принимают ровно одну включённую привязку. Сервер повторно проверяет это правило и не полагается только на интерфейс.

## Уведомление о версии

- Текущая версия, заголовок и краткое описание релиза хранятся в общем пакете.
- После обновления контейнеров и успешной проверки здоровья deployment запускает команду создания системного уведомления владельцу.
- Уведомление создаётся один раз на версию и содержит номер версии, заголовок и краткое описание.
- Повторный запуск deployment не создаёт дубль.

## Проверка

- Компонентные тесты проверяют верхний плюс, одиночный выбор платёжки, фильтрацию каталога и компактные переключатели.
- API-тесты проверяют запрет двух платёжных систем, сохранение доступности каталога и отсутствие дублей уведомления.
- Выполняются typecheck, полный unit-набор, production build и мобильные Playwright-сценарии Android/iPhone.
