# Компактное отображение цен

## Цель

Во всех пользовательских и административных экранах показывать целые денежные суммы без лишних нулей: `500 ₽` вместо `500,00 ₽`. Если сумма содержит реальные копейки, они сохраняются: `500,50 ₽`.

## Решение

Единая функция `formatPaymentMoney` остаётся источником форматирования валют. Для `Intl.NumberFormat` задаются от нуля до двух дробных знаков. Персональные предложения переводятся с локального форматтера на эту общую функцию, поэтому тарифы, профиль, платежные журналы и персональные ссылки используют одинаковое правило.

## Границы

- Валюта и разделители локали `ru-RU` сохраняются.
- Целые суммы не содержат дробной части.
- Ненулевые копейки не округляются и не скрываются.
- Бизнес-логика, расчёты, API и хранение сумм не изменяются.

## Проверка

Модульные тесты покрывают RUB, USD и EUR с целыми и дробными суммами. Клиентский E2E-сценарий ожидает новый вид цены. Затем выполняются полные проверки web, API, shared, сборка и публикация.
